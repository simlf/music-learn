<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user tap -> ChoiceGrid selectChoice | Untrusted choice selection grades an identification answer |
| user click -> Next | Advances the loop; draws a new generated question |
| in-memory score state | Session-only tally, no persistence boundary crossed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-11 | Injection (XSS) | rendering choice symbols and revealed symbol in the DOM | low | mitigate | Choices come from generateQuestion (fixed matrix, all `spellChord`-parseable), rendered via Svelte text interpolation (auto-escaped), never `{@html}`. No user-supplied text reaches the DOM. |
| T-03-12 | Spoofing | correctness of identification grade | low | mitigate | Grade is a direct `choice === question.symbol` string compare against the generator's own correct symbol; the correct option and distractors are distinct by construction (Plan 01 excludes enharmonic-identical distractors), so no ambiguous tie. |
| T-03-13 | Tampering | in-memory score integrity | low | accept | Score is ephemeral `$state`, no persistence/network (D-10); a reload resets it by design. No integrity boundary to protect. |
| T-03-14 | Denial of Service | Next -> generateQuestion draw | low | mitigate | generateQuestion is bounded/total (Plan 01); one draw per Next, no loop. |
| T-03-SC | Tampering | npm/pip/cargo installs | n/a | accept | No package installs in this plan; all dependencies already vetted in Phase 1. No legitimacy checkpoint required. |
</threat_model>
