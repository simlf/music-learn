<task type="auto">
  <name>Task 1: iOS meta tags in src/app.html + 180x180 apple-touch-icon</name>
  <files>src/app.html, static/icons/apple-touch-icon-180.png</files>
  <read_first>
    @src/app.html            (current head: manifest link, theme-color, one apple-touch-icon=icon-192, viewport)
    @static/manifest.webmanifest   (theme_color #221e17, background_color #f2ecdd — status-bar choice must fit the dark chrome)
  </read_first>
  <action>
    First generate the icon: from the existing `static/icons/icon-512.png`, produce a 180x180 PNG at `static/icons/apple-touch-icon-180.png` using the macOS built-in tool (this executes on darwin):
    `sips -z 180 180 static/icons/icon-512.png --out static/icons/apple-touch-icon-180.png`
    Confirm the output file exists and is 180x180. (No new art — derived from the existing icon, per 22-CONTEXT PWA-02.)

    Then edit `src/app.html` head (currently links the manifest, theme-color #221e17, one apple-touch-icon pointing at icon-192, and the viewport). Add the iOS presentation meta tags and repoint the apple-touch-icon:
    - `<meta name="apple-mobile-web-app-capable" content="yes" />`
    - `<meta name="mobile-web-app-capable" content="yes" />` (the newer standards name)
    - `<meta name="apple-mobile-web-app-status-bar-style" content="black" />` — use `black` (not `black-translucent`) so the status bar does not overlay content on the dark #221e17 chrome; the app has no safe-area-inset handling, so a translucent bar would let content slide under the notch.
    - `<meta name="apple-mobile-web-app-title" content="Music Learn" />`
    - Replace the existing single `apple-touch-icon` link so it points at the new 180 asset with an explicit size: `<link rel="apple-touch-icon" sizes="180x180" href="%sveltekit.assets%/icons/apple-touch-icon-180.png" />`
    Keep every existing tag (manifest link, theme-color, viewport, favicon) intact. No em dashes in any attribute value or comment.
  </action>
  <verify>
    <automated>test -f static/icons/apple-touch-icon-180.png && npm run check</automated>
  </verify>
  <done>The 180x180 apple-touch-icon exists; app.html contains the four apple/mobile web-app meta tags and an apple-touch-icon link (sizes 180x180) to the new asset; theme-color, manifest link and viewport are unchanged; svelte-check is 0 errors.</done>
