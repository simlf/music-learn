Build `RecallMap.svelte` — the fact x mode grid (MEM-04) showing every theory fact's mastery state (not yet seen, due, weak, mastered) filterable by kind — and wire a Review/Map mode toggle into the `/recall` page alongside the existing Review-mode session from 11-05, completing the UI-SPEC's two-tab `/recall` contract.

</objective>
