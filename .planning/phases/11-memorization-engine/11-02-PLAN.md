<objective>
Create the pure fact-catalog module that enumerates every theory fact the memorization engine can schedule in Phase 11: 96 chord-formula facts (the proven 12-root x 8-quality reference matrix), 12 interval-size facts (the existing DRILL_INTERVALS pool), and 84 scale-degree facts (the 12 major-scale tonics x 7 degrees) — all derived from the existing theory engine, per CONTEXT.md D-06 ("Facts are generated from tonal so the deck stays in sync with the theory engine").

Purpose: this is the "menu" of everything the deck (11-03) can seed a card for, and what the recall map (11-06) enumerates as rows. Keeping facts as thin identity references (not denormalized note data) means every surface that renders a fact's prompt/reveal content goes through the same spellChord/intervalFromShort/majorScaleNotes functions Drills and Scales already use — there is exactly one source of truth for what a chord's notes or a scale degree's letter are.
Output: `src/lib/srs/facts.ts` and its passing test file.
</objective>
