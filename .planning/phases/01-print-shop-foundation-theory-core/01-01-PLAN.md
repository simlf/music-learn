<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → build | Third-party packages enter the build (supply chain) |
| user input → theory engine | The typed chord symbol string is untrusted text parsed by `tonal` / `spellChord` |

Honest surface note: this is a single-user, fully static, client-only app with no backend,
no auth, no PII, and no network calls at runtime. The realistic surface is dependency supply
chain and untrusted chord-symbol string handling only.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs (SvelteKit, tonal, tailwind, vitest, adapter-static) | high | mitigate | All packages are pinned to exact versions with rationale + sources in `.claude/CLAUDE.md` (serves as the Package Legitimacy Audit for this vetted stack). No `[ASSUMED]`/`[SUS]`/`[SLOP]` packages are introduced; Task 1 forbids react-piano, @tonejs/piano, and any unvetted addition. End-of-phase human-check confirms `package.json` matches the pinned CLAUDE.md list before the phase closes. |
| T-01-DoS | Denial of Service | `spellChord` parsing untrusted input | low | mitigate | `tonal`'s `Chord.get` is a pure bounded parse over a short string; the input field caps length and the function returns a result object rather than throwing on malformed input (full non-blocking error handling lands in Plan 04 per D-08). |
| T-01-INJ | Tampering | rendering the chord symbol / note names in the DOM | low | accept | Svelte auto-escapes interpolated text; note names are rendered as escaped text, never via `{@html}`. No sink for injection in this static client app. |
</threat_model>
