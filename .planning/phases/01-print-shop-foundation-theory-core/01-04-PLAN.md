## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → build | `tone@15.1.22` enters the build |
| user input → showcase → engine/audio | Typed chord symbol drives rendering and synth playback |
| user gesture → Web Audio | Audio starts only on an explicit user action (autoplay policy) |

Honest surface note: static client-only app, no backend/auth/PII/persistence. Realistic
surface is the single new dependency (`tone`) and untrusted chord-symbol string handling.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | tone@15.1.22 (supply chain) | high | mitigate | `tone` is pinned to the exact vetted version with source/rationale in `.claude/CLAUDE.md` (Package Legitimacy Audit). Task 3 forbids `@tonejs/piano` and any other addition. End-of-phase human-check confirms `package.json` matches the audited pin list before phase close (T-01-SC carried across all Phase-1 plans). |
| T-01-INJ | Tampering | rendering symbol/notes + error hints in DOM | low | accept | Svelte auto-escapes all interpolated text (symbol, notes, hints); no `{@html}` sink. |
| T-01-DoS | Denial of Service | unbounded/rapid audio triggers | low | mitigate | `playChord` uses a single lazily-initialized synth and fixed short `triggerAttackRelease` durations; playback is gated behind an explicit user gesture, so no auto-loop or autoplay path exists. |
| T-01-INP | Denial of Service | malformed symbol via input or surprise-me | low | mitigate | `spellChord` returns `recognized:false` for bad input (non-blocking error path, D-08); `randomChord` only draws from the known supported space, so it never produces an unrenderable symbol. |
</threat_model>
