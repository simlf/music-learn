    - weakest contains only needsPractice items, sorted worst-accuracy-first, tie-break by more attempts then alphabetical by item, capped at 5.

Group rows by `${item}|${kind}`; for each group compute attempts and accuracy (correct/attempts); set needsPractice = attempts >= 3 && accuracy < 0.7. items = all groups sorted alphabetically by item then kind (easy to scan). weakest = items.filter(needsPractice) sorted by accuracy ascending, then attempts descending, then item ascending, sliced to 5.
