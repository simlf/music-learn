<objective>
Build the local-first confidence log that backs sketch-020-B: capture an optional pre-reveal confidence rating (? not sure / ~ somewhat / ! certain, or unrated when skipped) alongside whether the answer was correct, and aggregate it into the /progress calibration payoff view (calibration bars + danger cards).

Purpose: sketch 020-B is LOCKED — optional inline dots that never block Reveal, with skips logged "unrated"; sketch 020-C is its companion payoff surface. This plan owns the pure persistence + aggregation so 25-06 (capture in Recall) and 25-08 (payoff on Progress) are thin.
Output: `src/lib/practice/confidenceLog.ts` + TDD suite. Persistence is a capped localStorage ring buffer (documented choice — see below), keeping the critical cards Dexie database untouched (no schema migration risk).

Design decision (documented discretion): localStorage over Dexie for this log. The log is small (one tiny record per graded review, single user), and localStorage matches the established music-learn:* lightweight-log convention (songs.ts, recentLookups.ts, songFilterPref.ts). A ring-buffer cap bounds growth. Dexie is noted as the migration path if volume ever outgrows localStorage; it is deliberately not used here to avoid a version bump on the cards store.
</objective>
