Output: New seed channel + source variant + drills-page tag, all tested at the pure layer and at the page render.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → drills page | Seed symbols read from the browser's localStorage (both the drill and the new lesson channel) cross into session construction. localStorage is user-writable via devtools on a single-user local-first app. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-02-01 | Tampering | consumeLessonSeeds (localStorage input) | low | mitigate | Mirror the existing defensive contract: JSON parse in try/catch, non-string entries filtered out, [] on corrupt/unavailable. A tampered lesson-seeds value cannot inject non-string symbols or crash session init; unknown symbols simply fail to draw a question and fall through to the pool. |
| T-19-02-02 | Spoofing | seed origin labelling | low | accept | The origin flag is a local UX label only (which tag string renders); it grants no capability and no trust decision hangs on it. A user forging origin 'lesson' merely sees a different tag on their own device. |
| T-19-02-03 | Denial of Service | seed queue size | low | mitigate | Lesson seeds are the fixed two-symbol pair from Plan 19-01; even a tampered lesson-seeds array feeds the existing bounded session (length 10) and dedupe, so no unbounded growth. No package installs in this plan. |
</threat_model>
