<objective>
1C (UI half) — make Progress glanceable and actionable: a 7-day practiced strip on the streak hero, inline accuracy bars on every practice row (Weakest Spots and All-Stats), a per-row DRILL button that seeds one weak chord into /drills, and the bulk CTA renamed to "Drill all N".

Purpose: The streak is a bare numeral, accuracy is a read-not-see table, and weak rows are inert (only a bulk button). This closes the motivation loop with small, glanceable, tappable affordances.

Output: An accuracy bar + onDrill-gated DRILL button on `PracticeItemRow`, a 7-day strip + onDrill wiring + bulk-CTA rename on the Progress page, six new i18n keys, and updated tests.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-23-1C-U-03 | Tampering | per-row DRILL seed | low | accept | Reuses the existing setDrillSeeds one-shot localStorage channel (defensive read already in place); scoped to a single known chord symbol. |
