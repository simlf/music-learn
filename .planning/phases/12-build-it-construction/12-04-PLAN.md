## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| picker chip click -> construction target | The picker only ever selects from bounded, hardcoded arrays (ROOTS, QUALITY_SUFFIXES, MAJOR_SCALE_ROOTS) — there is no free-text input and no way to construct an out-of-catalog symbol/tonic. |
| PianoKeyboard tap -> gradeConstructionTap | Every tap is a (letter, octave) pair sourced from PianoKeyboard's own key data (12-02), passed straight through to the pure grader (12-03); no user-supplied string reaches persistence in this plan (no persistence exists yet). |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-12-07 | Denial of Service | handleConstructTap's timers | low | mitigate | Both the 320ms flash timer and the 650ms feedback timer are always cleared before being restarted and on component destroy (onDestroy), so no overlapping or leaked timers can accumulate across rapid taps. |
| T-12-08 | Tampering | picker selection state | low | accept | pickedRoot/pickedQuality/pickedTonic are only ever set from the bounded chip arrays via onclick handlers with hardcoded values — no dynamic/user-controlled string ever reaches createChordConstruction/createScaleConstruction. |
