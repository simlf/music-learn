<objective>
Build the pure, DOM-free construction engine at the heart of Phase 12: given a chord symbol or a scale tonic, derive the ascending, octave-strict sequence of notes the learner must tap one interval at a time, grade each tap by MIDI/chroma (never letters), and expose enough structured detail (per-step consecutive interval, role, degree) for the UI layer to phrase every instruction and WHY line without re-deriving any theory itself.

Output: `src/lib/practice/construction.ts` and its passing test file, including a full 96-chord + 12-scale reachability sweep.

Symbols this plan creates in `src/lib/practice/construction.ts`:
- `export type ConstructionKind = 'chord' | 'scale'`
- `export interface ConstructionStep { index: number; total: number; degree: number; letter: string; solfege: string; role: IntervalRole; midi: number; interval: IntervalInfo }`
- `export interface ConstructionState { kind: ConstructionKind; label: string; steps: ConstructionStep[]; position: number; earnedNotes: SpelledNote[]; wrongTapCount: number; done: boolean }`
- `export interface ConstructionTapResult { outcome: 'correct' | 'wrong-pitch-class' | 'wrong-octave'; state: ConstructionState; semitones?: number; direction?: 'high' | 'low' }` — `state` is ALWAYS present (advanced on 'correct', otherwise the same position with `wrongTapCount` incremented by one); `semitones`/`direction` are present only on 'wrong-pitch-class'.
- `export function createChordConstruction(symbol: string): ConstructionState`
- `export function createScaleConstruction(tonic: string): ConstructionState`
- `export function expectedStep(state: ConstructionState): ConstructionStep | undefined`
- `export function gradeConstructionTap(state: ConstructionState, letter: string, octave: number): ConstructionTapResult`
- `export function isNotableSpelling(letter: string): boolean`
- `export const CONSTRUCTION_BASE_OCTAVE = 4`

Design notes to follow exactly:
- `label` is the chord's own glyph symbol (root + quality, e.g. `"Cm7"` reconstructed the same way `chordPresentation.ts`'s `aliasLine`/`RecallMap`'s `chordLabel` do: `chord.root + chord.symbol.slice(chord.root.length)`) for chords, or the plain tonic (e.g. `"F♯"`) for scales.
- `steps[k].degree` = `k + 2` for both kinds (the root is degree/position 1, pre-placed, never a step) — meaningful for scale WHY-line phrasing ("degree {n}"), harmless/unused for chords.
- `earnedNotes` always starts as `[fullNotes[0]]` (the root, role `'root'`) and grows by exactly one `SpelledNote` per correct tap, always in the SAME spelling the target's own notes array already carries (D-02) — never re-derived.
- `gradeConstructionTap` on an already-`done` state is inert: return `{ outcome: 'wrong-pitch-class', state, semitones: 0, direction: 'high' }` (the SAME, unadvanced `state` object echoed back, so the caller never advances further) — total, never throws.
- Unrecognized/malformed input (an unrecognized chord symbol, or a tonic majorScaleNotes can't spell) returns an inert, already-`done` state with empty `steps`/`earnedNotes` — provably unreachable in practice since Phase 12's UI only ever passes catalog-drawn symbols/tonics, but kept for total-function correctness matching this codebase's established convention (see deck.ts's `deriveCellState` fallback comment).
