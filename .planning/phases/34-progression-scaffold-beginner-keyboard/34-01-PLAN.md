<objective>
Add the self-contained FSRS maturity read to `ProgressionDrill.svelte` and use it to deliver SCAF-02: at beginner level the play-step keyboard is reduced to the tonic's one octave and widens to the full two-octave span as the current bar's chord card matures. This plan also establishes the shared `stage` signal (and the `cardsLoaded` gate) that Plan 34-02's hint-ladder fade builds on.

Purpose: A cold beginner item's two-octave keyboard was part of what made the earn-the-symbol progression drill overwhelming (sketch 024). Reducing to one octave until the card matures is SCAF-02.

Output: `ProgressionDrill.svelte` reads the current bar's card maturity via the shipped `voicingStageForChord`, passes an explicit octave count to `PianoKeyboard`, and shows a beginner caption at one-octave span. The two existing tests that render this component gain a deck mock (mandatory: there is no global fake-indexeddb, so the new deck read would otherwise fail), plus new SCAF-02 coverage.
</objective>
