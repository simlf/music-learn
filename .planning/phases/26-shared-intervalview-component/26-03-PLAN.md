<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ChordResult prop -> rendered DOM | Chord data (letters, solfège, labels) is interpolated into the DOM; a rendering-injection sink would be the risk. |
| user click -> onInspectTone callback | Clicks cross into the parent-supplied handler; the component must not fabricate or replay events. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-03-XSS | Information Disclosure | tone/gap label rendering | medium | mitigate | Render every string via Svelte's auto-escaped `{...}` interpolation; never `{@html}`. Chord data originates from trusted spellChord. |
| T-26-03-A11y | Denial of Service | gap markers as focus stops | low | mitigate | Gap markers are `aria-hidden` non-button spans, so screen-reader users tab only between real tone buttons; no unlabelled focus traps. |
| T-26-03-DoS | Denial of Service | extended-chord wrap layout | low | mitigate | flex-wrap layout tested against extended chords; no fixed-width overflow that could break the page (drop to --spacing-xs only if 390px overflow observed). |
| T-26-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager installs; reuses existing house components (IntervalChip, Button). |
</threat_model>
