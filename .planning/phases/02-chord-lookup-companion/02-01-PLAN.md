<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user text input -> spellChord | Untrusted free-text chord symbols cross into the parser. |
| route/pathname -> masthead active-state | SvelteKit-controlled `$page.url.pathname`, not user-injected. |

## STRIDE Threat Register

ASVS level 1, block on high. Single-user, client-side static app: no auth, no server trust boundary this plan.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of Service | spellChord input from the lookup form | low | mitigate | spellChord is already total (returns recognized:false, never throws — verified Phase 1 chord.ts roleForDegree fallback); the page's non-blocking else branch surfaces a hint and never crashes the render. |
| T-02-02 | Tampering | rendered chord symbol / note letters in markup | low | accept | Values originate from tonal's dictionary and the user's own typed symbol echoed via Svelte's auto-escaping text interpolation (no {@html}); no injection surface for a single-user local app. |
| T-02-03 | Information Disclosure | masthead nav / route exposure | low | accept | Only static public routes (/ , /showcase) are linked; no sensitive data exists in this single-user app. |
</threat_model>
