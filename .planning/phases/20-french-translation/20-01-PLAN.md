## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → app | The persisted `music-learn:locale` value is device-local state read at startup; treated as untrusted input. |
| dictionary strings → DOM | Author-provided static translation strings are interpolated into the DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-01 | Tampering | locale.svelte.ts readStoredLocale/initLocale | low | mitigate | Accept only the exact literals 'en'/'fr' from localStorage; any other value falls back to 'en'. |
| T-20-02 | Injection (XSS) | t() render sites | low | mitigate | Translation values are static author-authored strings rendered as text via Svelte `{t(...)}` interpolation (auto-escaped); never via `{@html}`. No user free-text enters the catalog. |
| T-20-03 | Denial of Service | localStorage access | low | mitigate | All localStorage reads/writes are browser-guarded and wrapped in try/catch so private-mode/quota failures degrade to the in-memory EN default without throwing. |

No package-manager installs occur in this phase (hand-rolled i18n, zero new dependencies), so no supply-chain (T-{phase}-SC) checkpoint is required.
</threat_model>
