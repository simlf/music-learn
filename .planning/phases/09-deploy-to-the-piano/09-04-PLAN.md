<objective>
Make on-screen taps feel solid on a phone. Add an immediate press-down visual cue (a brief scale or shade) when a key is touched, on top of the existing ink-hatch selected state, so a fat-finger tap is instantly confirmable (D-11). Fire an optional light haptic via the Vibration API where supported (Android), feature-detected so it no-ops elsewhere (D-11). Respect prefers-reduced-motion for the press motion (D-11). Harden the keyboard surface against touch-gesture noise: disable double-tap zoom and the long-press callout/selection (D-12).

Purpose: Touch input hygiene and press feedback are what make the on-screen keyboard feel like a real instrument surface rather than a set of links. Depends on 09-02 (shares PianoKeyboard.svelte / app.css / components.test.ts). Scope is keyboard gestures only — pull-to-refresh blocking and leave-confirmation were offered and NOT selected (D-12).
Output: Press-cue + guarded haptic + gesture-hygiene styles on PianoKeyboard.

Covers decisions: D-11 (press feedback), D-12 (gesture hygiene, keyboard-only scope).
</objective>

## Phase Goal

**As a** phone-first pianist, **I want to** feel and see each key press land immediately without the page zooming or selecting text, **so that** tapping chords on glass feels crisp and reliable.
