    Create `src/lib/components/KeyboardDock.svelte`. Read the shared registry via `getDockRegistry()`; let `config = $derived(registry.current)`. When `config` is null, render nothing visible and set `--dock-height` to `0px`. When `config` is present, render the Dock Chrome Contract structure:
    (1) A handle `<button>` bar: solid `--color-ink` fill, `--color-paper-bright` text, `text-label font-mono uppercase`, centered, `min-height: 44px`, full width, `cursor: pointer`; label reads `Keyboard · tap to collapse` when expanded and `Keyboard · tap to expand` when collapsed (source strings natural-case, uppercased via the utility). A small horizontal grip bar (`--color-paper-bright` on ink) sits beside the label with `aria-hidden="true"`. Clicking the handle toggles a `collapsed` `$state` and calls `setDockedKeyboardCollapsed(collapsed)`.
    (2) Keyboard surface (rendered only when NOT collapsed): `--color-paper-bright` background, `2px solid --color-ink` top border, renders `{@render config.keyboard()}` at the keyboard's existing height. Do not force `overflow:hidden`; allow a hosted strip to scroll horizontally.

    Outer element: `position: fixed; left: 0; right: 0; bottom: 0; z-index: 50;` a `2px solid --color-ink` top border, the soft non-directional lift `box-shadow: 0 -4px 0 color-mix(in srgb, var(--color-ink) 6%, transparent)` (NOT Button's 3px offset motif), and `padding-bottom: env(safe-area-inset-bottom, 0px)`. Initialize `collapsed` from `readDockedKeyboardCollapsed()` at component init. Measure the dock's outer element with `bind:offsetHeight` into a `dockHeight` state and, in a browser-guarded `$effect`, write `document.documentElement.style.setProperty('--dock-height', ...)` (measured px when a config is present, `0px` when null or on teardown). Collapse/expand is an instant layout change (no keyframe); if any transition is added it must sit behind `prefers-reduced-motion: reduce` per app.css convention. Add NO sound-state control anywhere (Scope Decision 5). Write `keyboardDock.test.ts`: a small wrapper component that calls `setDockRegistry(createDockRegistry())`, registers a config whose `keyboard` snippet renders an identifiable element (e.g. a button labelled a test note) and whose `register` snippet renders text, then mounts `<KeyboardDock/>`.
