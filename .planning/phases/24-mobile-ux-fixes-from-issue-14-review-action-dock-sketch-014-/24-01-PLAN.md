<objective>
Fix issue #14 point 1: on mobile the Review (/recall) page sometimes blocks advancing because the Révéler button and the grade buttons fall below the fold and the user cannot scroll to them. Implement sketch 014 winner A (the action dock): a phone-only fixed bar pinned above the bottom tab bar that hosts each review mode's primary advance action, with page content scrolling above it. This is the structural guarantee (mirrors the 008-A docked-keyboard logic) — NOT sketch 014-C's auto-scroll, which is explicitly rejected as anything more than a day-one micro-fix.

Purpose: Guarantee the review loop is completable on a phone without scrolling, closing the most severe issue-#14 complaint (sometimes the user cannot advance at all).
Output: A phone-only action dock in RecallSession.svelte, a shared clearance token in app.css, any new i18n keys, and tests proving the docked actions are present and wired to the existing handlers.
</objective>
