<objective>
Recreate design-handoff sketch 2b in the real codebase: a semitone tick rail above the
piano board that names the interval between each consecutive pair of chord tones, read
where the notes actually are, next to the existing root-relative corner badges.
</objective>

<execution>
1. `app.css`: add `--color-gap-major: #5b7a8c` and `--color-gap-minor: #7d5a72` beside the
   existing interval-role tokens (new semantics, existing role tokens untouched).
2. `chordPresentation.ts`: extract `gapsBetween(notes)` from `stackedThirdsFor`'s inline
   map; `StackedGap` gains `short` (label without the "+" connective) and `semitones`.
   `stackedThirdsFor` calls it - no behavior change for existing consumers.
3. `PianoKeyboard.svelte`: add the `showIntervalTicks` prop, a `centerXFor(candidate)`
   helper resolving white/black key centers as board percentages, a `$derived` gap list
   (skipping gaps whose endpoints are missing or non-ascending after a D-02 wrap), and the
   rail markup rendered only on the unstacked branch, carrying the same board min-width so
   the two layers stay aligned inside the scroll wrapper.
4. `+page.svelte`: pass `showIntervalTicks` on the lookup keyboard.
5. Tests: rail rendering, third vs non-third treatment, black-key endpoint, narrow-gap font
   drop, stacked/1-note suppression, non-regression when the prop is omitted; plus
   `gapsBetween` coverage in the chordPresentation suite.
</execution>
