# Sketch 019: Shell Voicings

## Design Question

Backlog I-04: the LH shape real players use is a shell (3rd + 7th) or rootless voicing, not a root-position stack. Where does voicing style enter the app, and how does the keyboard communicate "these 2 notes are the full correct answer, the others are optional"?

## How to View

open .planning/sketches/019-shell-voicings/index.html

## Variants

- **A: Voicing selector** — 3-position selector (Root / Shell / Rootless A) above the drill prompt; shell reveal colors 3rd + 7th, renders root + fifth as hatched "optional" ghosts with a why-only-two teach panel.
- **B: Teach by subtraction** — guided-steps lesson (012-A pattern): show the full stack, then visibly drain root + fifth to ghost hatch on tap ("drop what the symbol already tells you"), keep the tritone.
- **C: Lookup compare** — voicings enter through lookup: every result gets 3 stacked cards (root / shell / rootless A) with when-to-use labels. No drill changes.
- **Synthesis: staged mix** — all three staged by FSRS card state: NEW shell card gets C's compare intro (once), LEARNING gets B's subtraction drain, REVIEW gets A's cold selector drill. Mirrors the 005 fading-scaffold rule.

## What to Look For

- Does the ghost-hatch + "R/5 optional" marker read as "allowed but not required", or as "wrong"?
- Is A's selector discoverable without explanation, and do the 3 labels fit at 390px in French (FONDAMENTALE will need abbreviation, cf. 013 register rule)?
- Does B's subtraction story land as the teaching moment before A-style drilling?
- Is C enough on its own for v1 of voicings, with A as the follow-up drill phase?
