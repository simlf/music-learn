Bar is roomier without the toggle, so the drill page itself has the same FR overflow to solve, just without the top-right control competing for width.

The real deliverable: every tight string stacked EN-above / FR-below. Red wavy underline or OVERFLOWS = the FR string is too wide for its Print Shop slot at the same font. This is the audit that scopes the i18n phase.

What breaks

  • FONDAMENTALE (root) is the killer: 12 chars vs ROOT's 4, blows every fixed register slot. Needs an abbreviation (FOND.) or a wider/2-line slot.
  • Grading A REVOIR and DIFFICILE stress the 4-across grade row; needs smaller type or 2x2 grid in FR.
  • Nav EXERCICES / THEORIE push the already-scrolling 6-item bar wider.
  • Chord glyph (Cmaj7, F♯ø7) is unaffected: symbols are language-neutral, serif size holds.
  • Body prompt "Nomme cet accord" fits fine; the danger is uppercase mono fixed-width slots, not sentences.
