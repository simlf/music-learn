Sketch 002 — Scale page, tonic-anchored

The scale should read as one clean run with the tonic at the left. Pick any tonic; watch it stay anchored. Compare three ways to anchor.

Today (the problem)

E♭ major renders on a fixed C-to-C two-octave span, so E♭ starts a third of the way in, C and D wrap into the second octave, and both ends sit blank. The tonic is not where the eye lands and the run looks scattered.

One octave, tonic to tonic. The literal black/white shape is preserved so you still see the real geometry, but the run always begins at the left edge.

Abstract: the seven degrees (plus the octave) as equal cells, 1 through 8, colored by degree role. Drops piano geometry entirely for a clean scale-shape read.

Anchored piano (variant A) with the scale-degree number under each in-key note, so you learn the shape and the numbering together.
