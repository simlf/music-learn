Sketch 009 · Hear the chord

On the FORMULA → BUILD reveal, how should HEARING the chord surface so audio memory locks in? Three ways to attach sound to the stamped-in answer card. One shared SOUND toggle demos both the on and the silent-fallback paths.

Sound:
audio engine armed · playChord() live

Variant A · sound fires on stamp-in, keys + glyph pulse in time

Cmaj7

 

The instant the answer stamps in, playChord(['C','E','G','B']) fires and the four lit keys plus the serif glyph pulse once, synced to the strike. Zero friction, the sound is just there. ↻ Hear again replays on demand. With Sound OFF the same reveal still pulses the keys and glyph visually and prints a muted register line, so the moment is never a silent dead end.

Variant B · reveal is silent, a letterpress HEAR IT button waits

Cmaj7

 

The reveal stamps in silent. A prominent letterpress speaker button sits beside the glyph, tapping it calls playChord() and pulses the keys + glyph. Respects a quiet room and puts the player in control of when audio happens. With Sound OFF the button dims to a muted state but still pulses the visual on tap and prints the muted register line, so the control is never a broken promise.

Variant C · roll root→3rd→5th→7th, each key lights as it sounds, then strike the block

Cmaj7

 

Auto-play, but the notes arpeggiate: root, then 3rd, then 5th, then 7th. Each key lights in its interval color and its register line prints the moment it sounds, then the full block chord strikes and every key pulses together. Strongest for mapping a heard pitch back to a named note. With Sound OFF the same stepped light-up and printed sequence still play out visually, just without tone.
