Sketch 005 · Always-on interval scaffold

How should an interval scaffold appear WHILE answering a construction drill (not just on reveal), and how should it fade out as the player levels up. Three placements of the same scaffold, one shared LEVEL control.

Level:

Variant A · formula strip above the keyboard

Click the notes for Cm7

Beginner shows each interval chip with its note name. Improving keeps the four chips but drops the note names, so the player must place the interval themselves. Confident removes the strip entirely, replaced with a dashed placeholder so the missing scaffold is visible in this mockup (in the real app the space just collapses).

Variant B · ghost labels on the target keys

Click the notes for Cm7

Beginner prints a faint interval + note-name label directly on each of the four target keys, so the answer key is legible before tapping. Improving keeps only the interval abbreviation at low opacity, no note name. Confident removes every ghost: the keyboard is fully blind, same as the finished, unscaffolded drill.

Variant C · interval recipe line above the prompt

Click the notes for Cm7

Beginner spells out each interval name with its note name in parentheses. Improving drops the parentheticals, keeping the interval names as words. Confident collapses the whole line to bare interval symbols (R + m3 + P5 + m7), the smallest scaffold that still states the formula.
