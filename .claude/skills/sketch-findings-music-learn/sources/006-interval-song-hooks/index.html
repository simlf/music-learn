Sketch 006 · Song-interval hooks

Every interval can carry a well-known tune as an ear-training aid, but only on tap. Never forced, never shown by default. Three surfaces for the same opt-in reveal.

Tap a row to reveal its tune, tap again to collapse

Each interval is a full-width row with its color swatch. Tapping opens a short strip beneath it with the tune name, tapping the same row again closes it. Only one hook is visible at a time per row, and nothing shows until asked for.

Tap a card to flip it, tap again to flip back

A tidy grid for browsing the whole interval set at a glance. Front shows the interval name in its color, back reveals the tune on flip. Good for a dedicated reference page where scanning many intervals at once matters more than reading one in context.

Pick an interval, then tap the hook button to append its tune to the register line

Reuses the app's existing mono inspect register (note · solfege · interval · French name · semitone count). The tune is an optional extra clause appended to that same line, toggled by its own button, so it reads as one more fact in the register rather than a separate UI element.
