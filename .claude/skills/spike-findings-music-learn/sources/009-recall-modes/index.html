Spike 009 — Multi-modal recall

One fact (e.g. Cm7), drilled from 4 directions. Feel whether hitting it from several angles deepens memory more than always going symbol → notes.

Rotation:
FACT 1/4 MODE A 0 CORRECT

Recall map

Each cell is one retrieval path to that fact. Multi-modal drilling lights up the whole row, not just one cue.

What each mode encodes

A recognition→production: see the symbol, play the notes (visual symbol → motor/spatial). The app's main direction.
B audiation→naming: hear the chord, pick the symbol (auditory → verbal). The risky one at beginner level — multiple choice, same root, so it tests quality by ear not root-finding.
C formula→build: given "1 b3 5 b7", build it (verbal/analytic → motor). Encodes the construction rule.
D notes→naming: see spelled notes, pick the symbol (spatial/visual → verbal). The reverse of A.
